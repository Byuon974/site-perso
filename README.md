## **Un portfolio pratique**

**Nexus** est une vitrine qui combine :

- **Architecture modulaire** avec Hugo
- **Design responsive** avec dark mode natif

## **Technologies clefs**

- **Hugo** (Go) pour la génération statique
- **Markdown** pour le contenu
- **Vanilla JS & CSS** pour l'interface
- **CI/CD automatisée** avec GitHub Actions
